## 4. NM05はチャットから開始

nm5に `startMode:'chat'` を追加し、template:'lookup'は維持する。このメタデータを持つサービスだけ、初期画面をチャット1列にし、左の照会欄／実行ボタン／runHintを出さない。初回から既存の日中サンプル発話chipとチャット入力欄を表示する。

```text
開始 → 初回chipまたは入力＋送信 → 既存consumeで第1ターン
     → 返答待ち → 第1回答＋分析表表示 → 深掘りのチャット
     → 最後の回答＋既存まとめ1枚ボタン
restart → 初期チャットへ戻る（分析表・まとめは閉じる）
```

分析表は第1回答が実際に表示された後にだけ左へ表示し、左に入力欄や実行は復活させない。pending中は前の分析表を維持する。初回は表なし。DOMにはhiddenのwork-paneを用意し、遅延返答完了時にパネルとレイアウトを局所更新する。チャットや入力を作り直して二重消費しない。`[hidden]`が既存のdisplay指定に負けないようにする。

chipsHTMLの初回runHint条件はstartModeを考慮する。入力＋送信は既存sendChat／detectLang／qOverride、chipは既存data-act='chip'を使う。state.logの形・log.lengthで次ターンを決める契約・service id・template・他lookupの入口は変えない。NM-05の数値と修正済み台本、マーカー、まとめ1枚は保持する。
