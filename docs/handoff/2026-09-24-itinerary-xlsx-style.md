# 出張工程表（Excel）のスタイル規約

- 日付：2026-09-24
- レーン：**S**（文書のみ。データ層・トークン・共通レイヤーに触らない）
- 出所：GN-07「幹部来訪・出張のアテンド段取り」の実業務で、PM が実際に手を入れた版との差分から確定した
- 関連：`docs/dify/usecases/GN-07.md`（実装リファレンス）

GN-07 が出力する工程表、および PM の実務で使う Excel 工程表の**書式の決まり**。
中身（行程そのもの）ではなく、**見え方と言い回し**だけを扱う。

> 実案件の社名・人名・ホテル名・電話番号はこの文書に書かない（`CLAUDE.md` §2-10）。
> 例示が要るときは `data/world/` の架空世界の語を使う。

---

## 1. フォント

| 対象 | 指定 |
|---|---|
| 本文・見出し | **游ゴシック Regular / 11pt** |
| タイトル行 | 游ゴシック Regular / 14pt / 太字 |
| 凡例行 | 游ゴシック Regular / 10pt |
| 見出し行（表頭）・日付列 | 游ゴシック Regular / 11pt / 太字 |

- **BIZ UDPゴシックは使わない。**
- 空セルの既定フォントは ＭＳ Ｐゴシック（Excel の既定のまま。明示指定しない）。

## 2. 行の高さ

**指定しない。Excel の自動調整に任せる。**

- `openpyxl` では `row_dimensions[r].height` を**設定しない**（設定すると `customHeight` が立ち、Excel が自動調整しなくなる）。
- 11pt の自動高さは 1 行 ＝ 19pt。2 行なら 38、3 行なら 57 になる。**この 19 の倍数を手で書かない**——中身を直すたびに合わなくなる。
- 折り返しは `alignment(wrap_text=True, vertical='center')` で効かせる。

## 3. 列

| 列 | 内容 | 幅 |
|---|---|---|
| A | 日程（日ごとに縦マージ） | 11 |
| B | 曜日（日ごとに縦マージ） | 6 |
| C | 時間 | 14 |
| D | 行動場所 | 30 |
| E | 内容 | 50 |
| F | 対応者 | 26 |
| G | 費用 | 20 |
| H | 未確定・備考 | 34 |

- **A 列は日付型で持ち、表示形式 `m"月"d"日"` を付ける。**シリアル値のまま General にすると `46293` と表示される（実際に一度起きた事故）。
- 日付をまたぐ予定は、開始日の側に置き、内容に「（日付をまたぎます）」と書く。

## 4. 未確定の表し方

- 未確定の行は**薄いオレンジ `FCE4D6`** で塗る。
- H 列に **`❗` を先頭に付けて**、何が決まっていないかを書く。
- 凡例行（3 行目）に「■橙 ＝ 未確定。H 列に内容を記載」と置く。
- **確定したら塗りと ❗ を必ず外す。**橙が残っていると、決まったことまで未確定に見える。

## 5. 備考（H 列）に書くこと・書かないこと

**書く**——当日その場で役に立つ事実。

- 時差（「時差 −1 時間。現地 20:40 着」）
- 移動の目安（「夜間でも 60〜75 分」）
- 制約（「NH968 の 2 時間前に到着」「ホテル内のため移動なし」）
- 手配の状態（「デイユースは予約済み」）

**書かない**——決定の経緯や作業メモ。

- 「原案 40 分を 65 分に」のような、前の版との差分
- 「（PM 判断）」「（PM 確定）」のような、誰が決めたかの注記
- 「◯◯からの逆算」のような、時刻の算出根拠
- 自分で気づいたことの自慢（「◯◯なので△△で収まります」）

> 経緯は版管理と設計書で追う。**配る紙に載せるのは、読んだ人が当日動けるものだけ。**

## 6. 言い回し

- **既に枠がある時間の使い道は、枠の名前を残して括弧で足す。**
  例：`休憩` → `休憩（ゴルフクラブ選び）`
  `ゴルフクラブのお選び` と新しい行のように書かない。訪問団から見て「また予定が増えた」と映る。
- 参加者・ご案内者のような複数行の情報は、**全角スペースで詰めず改行で分ける。**
- 当日決めるものは「**◯◯が当日の状況により手配**」と書く。会場名を空欄にしない。

## 7. 連絡先ブロック（末尾）

**1 行の中で列の意味を揃える。**行ごとに「1 列目が名称」「1 列目が区分」と入れ替わらないようにする。

| 列（マージ） | 内容 |
|---|---|
| A:C | 区分（ご案内 / 宿泊 ◯/◯ / ゴルフ場 ◯/◯ / 緊急通報） |
| D:E | 名称・住所 |
| F:G | 電話 |
| H | 備考（メール・Fax・補足） |

- **住所は簡体字で書く。**タクシーや配車アプリで提示するため、日本語漢字に直さない。
- 名称は「日本語名（英語名／中国語名）」の順で 1 セルにまとめ、住所は改行して続ける。

## 8. ファイル名

`YYYY-MM_<案件名>_工程表[_vN].xlsx`

- 先頭に年月を付ける（例：`2026-09_…`）。
- 版番号は付けても付けなくてもよい。付けるなら最後。
