## 次に採番するとき

- 既存分類への追加：その分類の最大番号 +1（例：ナレッジに追加なら `KN-06`）
- 新しい大分類：2 文字の英小文字 id を決め、`XX-01` から
- 削除：行を消さず、成熟度欄を「廃止」にして残す（欠番の記録）
