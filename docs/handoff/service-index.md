# サービス台帳（管理番号一覧）

CLAUDE.md §2-11 の採番ルールに基づく台帳。**番号は永久欠番**（削除しても再利用しない）。
管理番号は内部 id から機械的に変換する（`kn2` → `KN-02`）ので、この表は参照用であり正本は `mock/js/data/catalog.js` の `SVCS` と `tools/regress.baseline.json`。

この台帳と `docs/service-map.md`（`npm run index` の生成物）は役割が違う。`service-map.md` は実ファイルの有無まで突き合わせた**常に最新の索引**（DSL・ユースケース文書・KB・テストの横断表）。この台帳は**分類コードの由来と欠番の記録**（採番ルール・次に採番するときの手引き）を残す場所。

## 次に採番するとき

- 既存分類への追加：その分類の最大番号 +1（例：ナレッジに追加なら `KN-09`）
- 新しい大分類：2 文字の英小文字 id を決め、`XX-01` から
- 削除：行を消さず、成熟度欄を「廃止」にして残す（欠番の記録）
