# 架空世界マスタ — カレンダー・文書番号体系

この会社・人物・数値はすべて架空です。実在の企業・製品とは関係ありません。

## 会計年度・締め日

- 会計年度：台本に明記なし（未確定）。月次報告は月末締め（`dc.js` DC-01「8月分」実績＝8月末締め）
- 週報：毎週提出（`nm.js` NM-03「第36週」表記）。曜日は台本に明記なし（未確定）
- 稼働日／祝日の扱い：台本に明記なし（未確定）

## 世界の「今日」

台本の大半（`kn.js`・`qa.js`・`dc.js`・`nm.js`・`en.js`・`gn.js`・`lg.js` 中心）は **2025 年 9 月前後**を暗黙の現在としている
（例：`2025-09-30`8 回、`2025-09-06〜27`各 2 回、材料ロット入荷 `2025-08-19`）。

**未統一（既知の食い違い）**：`pt.js`（パートナー連携 8 サービス）の一部は本文中に **2026 年**の日付を明示的に持つ
（例：「2026 年 9 月 6 日時点」「情報ベンダ データフィード…2026-09-06」「購買月報（2026 年 8 月分）」）。
`kn.js`/`dc.js` 側の 2025-09 前後という世界の現在と 1 年ずれている。本 PR では直さない（`mock/**` 不可侵）。
`data/world/README.md` の「未統一」一覧に記載し、`check-world.mjs` の報告対象とする。

## 文書番号の体系

台本に実際に出現する書式（**両方を正として明記**。年の桁数が 4 桁と 2 桁で混在しているのも既存の食い違いで、
本 PR では統一しない）：

| 書式 | 意味 | 例（出現回数） |
|---|---|---|
| `TR-YYYY-NNN` | 技術報告 | `TR-2024-007`(10) `TR-2023-041`(2) `TR-2024-102`(2) |
| `NC-YYYY-NNNN` | 不具合（Nonconformance） | `NC-2024-0118`(18) `NC-2025-0912`(2) ほか |
| `8D-YY-MMDD` | 8D 報告 | `8D-25-0912`(4) |
| `ECR-YY-NNNN` | 変更申請（Engineering Change Request） | `ECR-25-0088`(16) `ECR-24-0017`(4) `ECR-23-0041`(4) |
| `RFQ-YYYY-NNN` または `RFQ-YY-NNN` | 見積依頼 | `RFQ-2025-118`(6) `RFQ-26-031`(4)。**年桁が混在**（4 桁／2 桁） |
| `PO-YYMM-NNN` | 発注 | `PO-2508-035`(2) ほか |
| `C-YYYY-NNN` | 顧客案件番号 | `C-2025-118`(10) |
| `C-26NN-X` | 匿名個人 ID（顧客担当者などを匿名化する形） | `C-2609-A`〜`C-2609-D`（各 2） |
| `RG-YY-NNNN` | 稟議（社内決裁） | `RG-25-0117`(20)。設計書の 7 種一覧には無いが台本に実在するため追加 |
| `CL-YY-MMDD` | クレーム対応番号 | `CL-25-0906`(14) |
| `QR-YYYY-QN-NN` | 品質報告（KB 文書） | `QR-2026-Q2-05`（`dify/kb/KN-01/不具合報告_2026-Q2_抜粋.md`） |
| `WS-XX-NNN` | 作業標準書 | `WS-QC-031`（`dify/kb/KN-01/作業標準書_寸法検査.md`） |
| `PC-LN-YYYY-NNN` | 工程条件書 | `PC-L3-2026-014`（`dify/kb/KN-01/工程条件書_旋盤ライン3.md`） |
| `CM-NN` | 変更管理規定（社内規程番号） | `CM-01` |
| `QC-NN` | 品質様式・検査基準番号 | `QC-11`（初品検査記録）`QC-27`（脱脂液濃度チェックシート）`QC-31`（碁盤目試験） |
| `VST-YYYY-NNN` | 出張・来訪案件番号（GN-07） | `VST-2025-014`（設計書 2026-09-08-exec-visit-attend.md §4-4）。3 文字接頭にしているのは `tools/check-world.mjs` W7 の「管理番号形式（`^[A-Z]{2}-\d{2}$`）と紛らわしい」報告を避けるため |
