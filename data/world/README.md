# data/world — 架空世界マスタ

台本（`mock/js/data/scenarios/**`）・KB 用ダミー文書（`dify/kb/**`）・テスト入力（`dify/tests/**`）・
ユースケース文書（`docs/dify/usecases/*.md`）に共通して登場する、架空の会社・人・品番・設備・数字の**正本**。

出典：`docs/handoff/2026-09-07-repo-layout-v2.md` §2（設計）。Issue #84 PR-1 で新設。

**この会社・人物・数値はすべて架空です。実在の企業・製品とは関係ありません。**

## 2 つの世界（製造業／金融）

`docs/handoff/2026-09-08-finance-catalog.md`（Issue #120）で金融（在中日系銀行）の第 2 世界を新設した。

- **製造業**：このディレクトリ直下のファイル（`company.md` 以下、下表）。青嶺精工／蘇州工場の世界
- **金融**：`data/world/fin/`（下記「金融の世界」）。瑞央銀行／上海本部の世界
- **2 つの世界の語彙は混ぜない**。金融の台本・KB・テストは `data/world/fin/` にある値だけを使い、製造業マスタの語（青嶺精工・K 社・PX-200 など）を流用しない
- 製造業側を `data/world/mfg/` へ移すのは別 PR（`2026-09-08-finance-catalog.md` の PR-1）の作業。**本 PR（PR-2）では移動していない**——移動すると PR-1 と同じファイルを同時に触ることになり衝突するため、迷った場合の指示（新設ディレクトリだけ足す）に従った。製造業側は当面このディレクトリ直下のまま参照する

## 重要な原則（load-bearing。`docs/handoff/2026-09-07-repo-layout-v2.md` §2-1）

**`data/world/` は正本だが、自動反映はしない。** モックのデータ層も KB 文書も、マスタから生成しない
（台本は文脈で表現が変わる：目標値・前月値・当月値）。`tools/check-world.mjs` は**報告するだけ**（FAIL にしない）。

## 追加時のルール

1. **新しい人名・社名・品番・設備・数字を出すときは、まず `data/world/` に足す。** 台本・KB 文書・テストはマスタにある値だけを使う
2. 既にある値を**別の文脈で違う数字にしたい**とき（改善事例など）は、`kpi.csv` に行を足して `note` で文脈を書く。台本側に裸の新しい数字を書かない
3. **取引先に社名を付けない**（PM 決定 PT-8）。記号（`K 社`）と役割名だけ。空白は `K 社`（半角スペース）に揃える — 既存の `K社` 8 か所は本 PR では**直さない**（`mock/**` 不可侵）。`tools/check-world.mjs` が warn として出し続ける
4. 実在の企業名・型番・URL・人名を混ぜない（`docs/dify/implementation-guide.md` §5-3）
5. 個人情報の見本（身分証 18 桁・電話 11 桁）は**架空値**を `people.csv` に持たず、テスト側（`dify/tests`）にだけ置く

## `tools/check-world.mjs` の読み方

```
node tools/check-world.mjs            # 報告のみ。常に exit 0
node tools/check-world.mjs --strict   # 1 件でも不一致なら exit 1（食い違いを潰す PR で使う）
npm run world                          # = node tools/check-world.mjs
```

出力は W1〜W9 の検査ごとに件数と代表例を出す（詳細は `tools/check-world.mjs` の冒頭コメント）。
**CI には入れない**（`npm test` に足さない）。初版では上の「未統一」表に対応する warn が必ず出る。

**現時点のスコープ（金融追加後・PR-2 時点）**：`tools/check-world.mjs` は今のところ**製造業（このディレクトリ直下）だけ**を
検査する。金融（`data/world/fin/`）を読み込む台本・KB 文書・テストがまだ存在しない（`docs/handoff/2026-09-08-finance-catalog.md`
の PR-4 以降で追加される）ため、本 PR では検査対象に加えていない。金融の台本・KB が入ったら、`mfg`/`fin` を対にして
回すよう `check-world.mjs` を拡張すること（設計書 §7-2）。今のところ `data/world/fin/**` を足しても
`npm run world` の warn 件数（19 件）は変わらない。
